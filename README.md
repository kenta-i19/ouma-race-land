# 🥕 にんじんダービー（CARROT DERBY）

**べんきょうして にんじんコインを あつめ、あいばを そだてて おうまレースへ！**

「うま」×「がくしゅう」×「けいば」を くみあわせた、こどもも おとなも たのしめる いくせいゲームです。

---

## 🎮 ゲームのながれ

1. **べんきょうする** — ひらがなの もんだいに こたえると、ごほうびに「にんじんコイン 🥕」が もらえます。
2. **あいばを そだてる** — じぶんの おうまを むかえて、コインで トレーニング。すばやさ・スタミナ・こんじょうを のばし、レベルアップ させます（RPGパート）。
3. **おうまレース** — そだてた あいばで しゅつそう！ コインを かけて、ドキドキの レースを かんせん。
4. **あたり・はずれ／じゃくにくきょうしょく** を たのしみながら、また べんきょう・トレーニングを くりかえします。

### こどもむけの くふう

- 💰 おかね ではなく **「にんじんコイン」**（うまの だいこうぶつ！）。げんきんは いっさい つかいません。
- 📚 コインは **べんきょうで いつでも ふやせる** ので、ゼロになっても こまりません（＝まなびに もどる どうせん）。
- 🔊 まだ もじが よめない 4さいじ のために、**おんせい よみあげ**（Web Speech API）で もんだいを よみあげます。
- 👆 ぜんぶ **おおきな ボタンの タップそうさ**。キーボード にゅうりょくは いりません。

> ⚠️ 本物の おかね・かけごとは いっさい あつかいません。あくまで がくしゅうの どうきづけと、「あたり・はずれ」の たいけんを たのしむための ゲームです。

---

## 🧩 いまの きのう

| きのう | ないよう |
| --- | --- |
| ひらがな がくしゅう | え（emoji）を みて、ただしい ひらがなを 3つから えらぶ |
| あいば いくせい（RPG） | じぶんの うまを むかえ、きゃくしつ を えらび、トレーニングで ステータス UP。けいけんち・レベル・つかれ・なかよし度 を かんり |
| おうまレース | そだてた あいばが ライバルと きょうそう。きゃくしつ（にげ／せんこう／さし／おいこみ）・スタミナ・こんじょう で じゅんいが いれかわる、ほんかくシミュレーション |
| レースえんしゅつ | カウントダウン → リアルタイムじゅんい → じっきょうテロップ → ラストスパート → しゃしんはんてい → ひょうしょうだい |
| データほぞん | ブラウザ（localStorage）に コイン・せいせき・あいば を ほぞん |

### レースの しくみ（おとなも たのしめる ポイント）

- うまは **きゃくしつ** ごとに ペースが ちがい、レースちゅうに せんとうが いれかわる。
- **スタミナ** が きれると しゅうばんで たれ、**こんじょう** が たかいと ゴールまえで のびる。
- レースごとの「**ちょうし**」らんすうで、**ばんくるわせ**も おこる（つよい あいばでも たまに まける）。
- **つかれ** が たまると よわくなるので、ごはん・おやすみでの ケアが だいじ。
- オッズは じつりょくに れんどう。じぶんの あいばを そだてると にんき馬に。

### これからの よてい（ロードマップ）

- ➕ がくしゅうもんだいの ついか：**カタカナ・たしざん・ひきざん**（`lib/words.ts` / `lib/game.ts` を かくちょう）
- 🏆 レースの ランク（G3→G1）や きょうてきライバルの ついか
- 🐴 ふくすうとう の いくせい・けっとう（こうはい）
- 👨‍👩‍👧 ほごしゃむけ：がくしゅうの きろく・むずかしさ ちょうせい

## 🛠 ぎじゅつ

- [Next.js](https://nextjs.org/)（App Router）+ React + TypeScript
- データほぞんは ブラウザの `localStorage`（サーバー・アカウントとうろく ふよう）
- がいぶライブラリ なし（CSS アニメーション・Web Speech API のみ）

## 🚀 うごかしかた

```bash
cd ouma-race-land
npm install
npm run dev
# ブラウザで http://localhost:3000 をひらく
```

### ほんばんビルド

```bash
npm run build
npm run start
```

### デプロイ（Vercel）

このプロジェクトは リポジトリの サブフォルダ `ouma-race-land/` にあります。
Vercel では **Root Directory** を `ouma-race-land` に せっていして デプロイしてください。
