# 🐴 おうまレースランド

**べんきょうして にんじんコインを あつめて、おうまレースで あそぼう！**

4さい〜小学生むけの、「うま」×「がくしゅう」×「けいば」を くみあわせた ちいくゲームです。

---

## 🎮 ゲームのながれ

1. **べんきょうする** — ひらがなの もんだいに こたえると、ごほうびに「にんじんコイン 🥕」が もらえます。
2. **おうまレース** — あつめた にんじんコインを かけて、すきな おうまを おうえん。
3. **あたり・はずれ** を たのしみながら、また べんきょうして コインを あつめます。

### こどもむけの くふう

- 💰 おかね ではなく **「にんじんコイン」**（うまの だいこうぶつ！）。げんきんは いっさい つかいません。
- 📚 コインは **べんきょうで いつでも ふやせる** ので、ゼロになっても こまりません（＝まなびに もどる どうせん）。
- 🔊 まだ もじが よめない 4さいじ のために、**おんせい よみあげ**（Web Speech API）で もんだいを よみあげます。
- 👆 ぜんぶ **おおきな ボタンの タップそうさ**。キーボード にゅうりょくは いりません。

> ⚠️ 本物の おかね・かけごとは いっさい あつかいません。あくまで がくしゅうの どうきづけと、「あたり・はずれ」の たいけんを たのしむための ゲームです。

---

## 🧩 いまの きのう（MVP）

| きのう | ないよう |
| --- | --- |
| ひらがな がくしゅう | え（emoji）を みて、ただしい ひらがなを 3つから えらぶ |
| おうまレース | 5とうの うまから 1とう えらび、コインを かけて レース |
| データほぞん | ブラウザ（localStorage）に コイン・せいせきを ほぞん |

### これからの よてい（ロードマップ）

- ➕ がくしゅうもんだいの ついか：**カタカナ・たしざん・ひきざん**（`lib/words.ts` / `lib/game.ts` を かくちょう）
- 🏆 レベルや バッジ、デイリーミッション
- 👨‍👩‍👧 ほごしゃむけ：がくしゅうの きろく・むずかしさ ちょうせい
- 📱 アプリか（React Native など）への てんかい

---

## 🛠 ぎじゅつ

- [Next.js](https://nextjs.org/)（App Router）+ React + TypeScript
- データほぞんは ブラウザの `localStorage`（サーバー・アカウントとうろく ふよう）
- がいぶライブラリ なし（CSS アニメーション・Web Speech API のみ）

## 🚀 うごかしかた

```bash
cd ouma-race-land
npm install
npm run dev
# ブラウザで http://localhost:3000 をひらく
```

### ほんばんビルド

```bash
npm run build
npm run start
```

### デプロイ（Vercel）

このプロジェクトは リポジトリの サブフォルダ `ouma-race-land/` にあります。
Vercel では **Root Directory** を `ouma-race-land` に せっていして デプロイしてください。
